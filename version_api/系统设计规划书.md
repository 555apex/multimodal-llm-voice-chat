# 基于两模态LLM的语音聊天系统 - 设计规划书

## 1. 项目概述

### 1.1 项目名称
基于两模态（文本+语音）LLM 的语音聊天系统

### 1.2 项目目标
构建一个支持文本和语音两种输入模态的智能聊天系统，具备：
- 键盘文本输入和麦克风语音输入
- LLM 智能推理和回复
- 文本显示和语音朗读双模态输出
- 卡通人物形象口型动画

### 1.3 技术选型

| 组件 | 技术方案 |
|------|----------|
| 前端框架 | Vue 3 |
| 后端框架 | Python Flask |
| 前后端通信 | WebSocket |
| 语音识别 (ASR) | mimo-v2.5-asr |
| 语音合成 (TTS) | mimo-v2.5-tts |
| 大语言模型 (LLM) | mimo-v2.5-pro |
| 卡通人物 | CSS 动画 |
| 部署方式 | 本地运行 |

---

## 2. 功能需求

### 2.1 输入功能

| 功能 | 描述 |
|------|------|
| 文本输入 | 用户通过键盘在输入框中输入文本，点击发送或回车提交 |
| 语音输入 | 用户点击语音按钮开始录音，再次点击停止录音，录音结束后自动识别并发送 |

### 2.2 处理功能

| 功能 | 描述 |
|------|------|
| 语音识别 | 将用户语音转换为文本 |
| LLM 推理 | 根据用户输入（文本/语音转文本）生成智能回复 |
| 语音合成 | 将 LLM 回复的文本转换为语音 |

### 2.3 输出功能

| 功能 | 描述 |
|------|------|
| 文本显示 | 在对话框中显示用户输入和 LLM 回复 |
| 语音朗读 | LLM 回复完成后自动朗读（默认开启） |
| 口型动画 | 朗读时卡通人物显示说话口型 |
| 音量控制 | 用户可调节朗读音量 |
| 朗读开关 | 用户可开启/关闭自动朗读 |

### 2.4 界面功能

| 功能 | 描述 |
|------|------|
| 卡通人物 | 显示在对话区域上方，带口型动画 |
| 对话历史 | 显示完整的对话记录 |
| 输入区域 | 包含文本输入框、语音按钮、发送按钮 |
| 控制区域 | 音量滑块、朗读开关 |

## 7. API 接口设计

### 7.1 mimo 开放平台 API

**基础信息：**
- 请求地址：`https://api.xiaomimimo.com/v1/chat/completions`
- 请求方法：`POST`
- 认证方式（二选一）：
  - 方式一：`api-key: $MIMO_API_KEY`
  - 方式二：`Authorization: Bearer $MIMO_API_KEY`
- 所有模型（LLM/TTS）共用同一 API 端点和 API Key

---

### 7.2 mimo-v2.5-pro (LLM) 接口

**请求示例：**
```json
{
  "model": "mimo-v2.5-pro",
  "messages": [
    {"role": "system", "content": "你是一个友好的AI助手"},
    {"role": "user", "content": "你好，请介绍一下自己"}
  ],
  "stream": true,
  "temperature": 1.0,
  "top_p": 0.95,
  "max_completion_tokens": 131072
}
```

**流式响应格式 (SSE)：**
```
data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","model":"mimo-v2.5-pro","choices":[{"index":0,"delta":{"content":"你"},"finish_reason":null}]}

data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","model":"mimo-v2.5-pro","choices":[{"index":0,"delta":{"content":"好"},"finish_reason":null}]}

...

data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","model":"mimo-v2.5-pro","choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}

data: [DONE]
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| model | string | 必填 | 模型 ID：`mimo-v2.5-pro` |
| messages | array | 必填 | 消息列表 |
| stream | boolean | false | 是否流式输出 |
| temperature | number | 1.0 | 采样温度 [0, 1.5] |
| top_p | number | 0.95 | 核采样阈值 [0.01, 1.0] |
| max_completion_tokens | integer | 131072 | 最大输出 token 数 |
| thinking.type | string | enabled | 思维链：`enabled` / `disabled` |

---

### 7.3 mimo-v2.5-tts (语音合成) 接口

**请求示例：**
```json
{
  "model": "mimo-v2.5-tts",
  "messages": [
    {"role": "user", "content": "请朗读以下内容"},
    {"role": "assistant", "content": "你好，今天天气真不错！"}
  ],
  "audio": {
    "format": "wav",
    "voice": "mimo_default"
  }
}
```

**响应格式：**
```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "model": "mimo-v2.5-tts",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "audio": {
          "id": "audio_xxx",
          "data": "UklGRi...",
          "expires_at": null,
          "transcript": null
        }
      },
      "finish_reason": "stop"
    }
  ]
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| model | string | 必填 | 模型 ID：`mimo-v2.5-tts` |
| messages | array | 必填 | 需包含 assistant 消息指定合成文本 |
| audio.format | string | wav | 音频格式：`wav` / `mp3` / `pcm` / `pcm16` |
| audio.voice | string | mimo_default | 音色 ID |
| stream | boolean | false | 流式输出时格式为 pcm |

**可用音色（mimo-v2.5-tts）：**
- `mimo_default` - 默认音色
- `冰糖` / `茉莉` / `苏打` / `白桦` - 中文音色
- `Mia` / `Chloe` / `Milo` / `Dean` - 英文音色

---

### 7.4 mimo-v2.5-asr (语音识别) 接口

**请求示例：**
```json
{
  "model": "mimo-v2.5-asr",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "input_audio",
          "input_audio": {
            "data": "data:audio/wav;base64,UklGRi..."
          }
        }
      ]
    }
  ],
  "asr_options": {
    "language": "auto"
  }
}
```

**响应格式：**
```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "model": "mimo-v2.5-asr",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "识别出的文本内容"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 100,
    "completion_tokens": 50,
    "total_tokens": 150,
    "prompt_tokens_details": {
      "audio_tokens": 100
    },
    "seconds": 5
  }
}
```

**关键参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| model | string | 必填 | 模型 ID：`mimo-v2.5-asr` |
| messages | array | 必填 | 包含 input_audio 类型的用户消息 |
| messages.content.type | string | 必填 | 固定值：`input_audio` |
| messages.content.input_audio.data | string | 必填 | data URL 格式的 Base64 音频 |
| asr_options.language | string | auto | 语种：`auto` / `zh` / `en` |
| stream | boolean | false | 是否流式输出 |

**支持的音频格式：**
- WAV：`data:audio/wav;base64,...`
- MP3：`data:audio/mpeg;base64,...` 或 `data:audio/mp3;base64,...`

## 8. 关键技术点

### 8.1 WebSocket 流式输出
- 使用 `flask-socketio` 实现 WebSocket 服务
- LLM 回复采用流式传输，逐字显示
- 使用 Socket.IO 支持自动重连

### 8.2 录音功能
- 使用 Web Audio API (`MediaRecorder`) 录音
- 采集为 WAV 格式
- 支持实时显示录音状态

### 8.3 音频播放
- 使用 Web Audio API 或 HTML5 Audio 播放 TTS 音频
- 支持音量控制
- 播放状态回调驱动口型动画

### 8.4 口型动画
- 使用 CSS animation 实现
- 定义 2-3 种口型状态（闭嘴、微张、大张）
- 根据音频播放状态切换
