# 大屏回调验收清单

版本：DGX d5b4d507 / GitHub c6160f6；日期：2026-10-20。宿主发布版本/注册位置/责任人：________。

| 场景与输入 | 预期结果 | 实际结果/证据/判定 |
|---|---|---|
| 独立页面未注册回调，输入“打开叫应界面” | 明确提示需在已接入大屏执行，不报成功 | |
| 宿主已注册，“打开叫应界面” | OPEN_COMMAND；回执与真实页面变化对应 | |
| “你是否支持大屏跳转？” | 中性解释“识别并提交指令、在已接入大屏执行”，不触发操作、不宣称已经接入 | |
| 带中文/英文引号和句末标点的“打开叫应界面” | 与无引号明确指令相同；仍由宿主回执决定结果 | |
| “打开物资界面” | OPEN_MATERIALS | |
| “打开福州南监控” | OPEN_MONITOR，name明确；实际画面对应 | |
| “打开监控” | 要求明确设备名，不自动猜测 | |
| “显示桥梁，隐藏隧道” | SET_MAP_RESOURCES，两项状态正确 | |
| “搜索附近资源，经度119.29734，纬度26.06979” | SEARCH_NEARBY_RESOURCES；按宿主坐标系检查 | |
| “搜索附近资源” | 澄清经纬度，不凭空定位 | |
| “如何打开叫应界面”或“不要打开叫应界面” | 不发送执行动作 | |
| 非白名单动作、all资源、重复资源、额外URL/脚本字段或越界坐标 | 参数拒绝，不执行 | |
| 回执requestId错误、缺data、非法status或宿主抛异常 | 失败/未确认；不得朗读操作成功 | |
| 30秒无有效回执 | 超时/未确认；核对宿主是否迟到执行，禁止盲目重试 | |
| accepted / completed / rejected / failed四类回执 | 正确显示；accepted不等于实际完成 | |

仅在隔离大屏执行操作；不把调用处理器本身当成操作成功。仅独立页面交付时，登记宿主联动“不适用”及范围确认；交付范围含大屏时，宿主未接入即未通过。普通交通/RAG/语音、SSE与应急链路仍按主手册验收。
