## 修复内容

1. 应急与设施查询使用请求序号及查询条件快照丢弃旧响应；切换后立即获取当前条件，自动刷新保留历史页码。
2. SSE 在完整缓冲区归一化 CRLF；未收到 `run.completed` 或 `run.failed` 就结束时报告中断，停止朗读并退出数字人回答状态。
3. 调度模型结果落库前核验领取时的工作流 `lockVersion`、方案 ID/版本和生成状态；旧成功和旧失败均不能覆盖后续重试。
4. DGX 的 vLLM 拒绝 Java 默认 h2c 升级请求，模型适配器固定 HTTP/1.1。保留 `enable_thinking=false`、既有请求超时，本次代理等待及生成陈旧阈值为 600 秒。
5. Qwen 曾将一个包含分号的完整预案占位符拆成多个键。增加完整复制、禁止拆分的提示及空对象示例；保留新版严格白名单校验和未知事实“待核实”规则。
6. 内网关闭分类轮询，公网开启分类轮询，避免共享库重复处理。
