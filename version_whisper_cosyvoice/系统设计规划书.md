# 基于两模态LLM的语音聊天系统 - 本地部署版 (Whisper + CosyVoice)

## 1. 项目概述

### 1.1 项目名称
基于两模态（文本+语音）LLM 的语音聊天系统 - 本地部署版

### 1.2 项目目标
构建一个支持文本和语音两种输入模态的智能聊天系统，采用本地部署的 Whisper 和 CosyVoice 模型，实现高质量、多语言的语音交互体验。

### 1.3 技术选型

| 组件 | 技术方案 | 部署方式 |
|------|----------|----------|
| 前端框架 | Vue 3 | 本地 |
| 后端框架 | Python Flask | 本地 |
| 前后端通信 | WebSocket | 本地 |
| 语音识别 (ASR) | OpenAI Whisper (large-v3) | 🖥️ 本地部署 |
| 语音合成 (TTS) | CosyVoice | 🖥️ 本地部署 |
| 大语言模型 (LLM) | mimo-v2.5-pro | ☁️ API 调用 |
| 卡通人物 | CSS 动画 | 本地 |
| 部署方式 | 本地运行 | - |

### 1.4 硬件要求

| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| GPU | NVIDIA 8GB 显存 | NVIDIA 16GB+ 显存 |
| 内存 | 16GB | 32GB |
| 硬盘 | 15GB 可用空间 | 30GB+ |
| CPU | 4 核 | 8 核+ |

## 2. 功能需求

### 2.1 输入功能

| 功能 | 描述 |
|------|------|
| 文本输入 | 用户通过键盘在输入框中输入文本，点击发送或回车提交 |
| 语音输入 | 用户点击语音按钮开始录音，再次点击停止录音，录音结束后自动识别并发送 |

### 2.2 处理功能

| 功能 | 描述 |
|------|------|
| 语音识别 | 使用 Whisper (large-v3) 本地识别语音为文本 |
| LLM 推理 | 调用 mimo-v2.5-pro API 生成智能回复 |
| 语音合成 | 使用 CosyVoice 本地合成语音 |

### 2.3 输出功能

| 功能 | 描述 |
|------|------|
| 文本显示 | 在对话框中显示用户输入和 LLM 回复（流式输出） |
| 语音朗读 | LLM 回复完成后自动朗读（默认开启） |
| 口型动画 | 朗读时卡通人物显示说话口型 |
| 音量控制 | 用户可调节朗读音量 |
| 朗读开关 | 用户可开启/关闭自动朗读 |

## 4. 工作流程

### 4.1 文本输入流程

```
用户输入文本 → WebSocket → LLM API (流式) → 流式显示 → CosyVoice 合成 → 播放音频
```

### 4.2 语音输入流程

```
用户录音 → WebSocket → Whisper 识别 → 显示识别文本 → LLM API (流式) → 流式显示 → CosyVoice 合成 → 播放音频
```

## 7. API 接口设计

### 7.1 前后端 WebSocket 消息格式

**客户端 → 服务端：**

```json
// 文本消息
{
  "type": "text",
  "content": "用户输入的文本",
  "auto_read": true
}

// 语音消息
{
  "type": "audio",
  "content": "base64编码的音频数据",
  "format": "wav",
  "auto_read": true
}
```

**服务端 → 客户端：**

```json
// LLM 流式文本回复
{
  "type": "text_chunk",
  "content": "当前生成的文字片段"
}

// LLM 回复完成
{
  "type": "text_complete",
  "content": "完整的回复文本"
}

// TTS 音频数据
{
  "type": "audio",
  "content": "base64编码的音频数据",
  "format": "wav"
}

// ASR 识别结果
{
  "type": "asr_result",
  "content": "识别出的文本"
}
```

## 8. 部署步骤

### 8.1 环境准备

```bash
# 创建虚拟环境
python -m venv venv
venv\Scripts\activate  # Windows

# 安装 PyTorch (CUDA 版本)
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121

# 安装其他依赖
pip install -r requirements.txt
```

### 8.2 配置

```bash
cp .env.example .env
# 编辑 .env 填入 MIMO_API_KEY
```

### 8.3 启动

```bash
# 后端
cd backend
python app.py

# 前端 (新终端)
cd frontend
npm install
npm run dev
```
