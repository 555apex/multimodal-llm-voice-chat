```python
class TTSService:
    def __init__(self):
        self._use_edge_tts = True  # 默认使用edge-tts
    
    def _init_model(self):
        # 优先使用edge-tts
        if self._use_edge_tts:
            import edge_tts
            self._initialized = True
            return
        
        # 尝试使用ChatTTS
        try:
            import ChatTTS
            # ...
        except Exception as e:
            # 回退到edge-tts
            import edge_tts
            self._use_edge_tts = True
            self._initialized = True
    
    def synthesize(self, text):
        if self._use_edge_tts:
            audio_bytes = asyncio.run(self._synthesize_edge_tts(text))
        else:
            audio_bytes = self._synthesize_chattts(text)
```

## 技术架构

### 系统架构
```
前端 (Vue 3)
    ↓ WebSocket
后端 (Flask + SocketIO)
    ↓
┌─────────────────────────────────┐
│  ASR: FunASR (Paraformer-zh)    │
│  TTS: edge-tts (XiaoxiaoNeural) │
│  LLM: mimo API (mimo-v2.5-pro) │
└─────────────────────────────────┘
```

### 数据流
1. 用户输入文本/语音
2. 如果是语音 → ASR识别为文本
3. 文本发送给LLM获取回复
4. LLM回复通过TTS合成为语音
5. 返回给用户

**问题描述**:

- 导致所有中文字符被当作 Emoji 删除

**修复方案**:
- 缩小 Emoji 匹配范围，只覆盖真正的 Emoji 区域
- 移除会误伤中文字符的范围

**修复前**:
```python
emoji_pattern = re.compile(
    "["
    "\U000024C2-\U0001F251"  # ← 这个范围太大，包含中文字符！
    "]+",
    flags=re.UNICODE
)
```

**修复后**:
```python
emoji_pattern = re.compile(
    "["
    "\U0001F600-\U0001F64F"  # 表情符号
```

### 20:30 - TTS 保留数学符号
**问题描述**:
- TTS 朗读时漏读小数点、^、括号等符号
- 例如 `3.14` 被读成 `3 14`，`f(x)` 被读成 `f x`

**根本原因**:
1. 括号 `()` 被正则删除：`text = re.sub(r'[#\[\]()>`~|]', '', text)`
2. 小数点被句子提取正则拆分：`[^。！？.!?\n]+[。！？.!?\n]`

**修复方案**:
1. 从删除列表中移除括号
2. 修复句子提取正则，英文句号后必须跟空格才断句

**修复前**:
```python
# 删除括号
text = re.sub(r'[#\[\]()>`~|]', '', text)

# 英文句号处断句（会拆分小数）
pattern = r'([^。！？.!?\n]+[。！？.!?\n])'
```

**修复后**:
```python
# 保留括号
text = re.sub(r'[#\[\]>`~|]', '', text)

# 英文句号后必须跟空格才断句（不会拆分小数）
pattern = r'([^。！？\n]+[。！？\n]|.+?[.!?](?:\s|\n|$))'
```

**测试结果**:
- `x^2 + y^2 = r^2` → 正确保留
- `3.14159` → 正确保留
- `f(x) = x + 1` → 正确保留
- `3 * 4 = 12` → 正确保留
- `$E = mc^2$` → 转为 `E = mc^2` 后朗读

**结果**: ✓ 数学符号保留功能完成
