# 设备迁移指南

本文档用于帮助将项目迁移到新设备上继续开发。

---

## 1. 环境要求

### 必需软件
- **Python**: 3.12 或更高版本
- **Node.js**: 16.x 或更高版本
- **NVIDIA GPU**: 支持 CUDA（推荐 8GB+ 显存）
- **NVIDIA 驱动**: 支持 CUDA 12.1+

### 硬件要求
| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| GPU | NVIDIA 8GB 显存 | NVIDIA 16GB+ 显存 |
| 内存 | 16GB | 32GB |
| 硬盘 | 10GB 可用空间 | 20GB+ |

## 2. 安装步骤

### 2.1 克隆/复制项目
将整个项目目录复制到新设备：
```
version_funasr_chattts/
├── backend/
├── frontend/
├── 开发日志.md
├── 设备迁移指南.md
└── README.md
```

### 2.2 安装后端依赖

```bash
cd backend

# 创建虚拟环境（推荐）
python -m venv venv
venv\Scripts\activate

# 安装 PyTorch (CUDA 12.1)
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121

# 安装其他依赖
pip install -r requirements.txt

# 安装 edge-tts（快速 TTS 备选）
pip install edge-tts
```

### 2.3 安装前端依赖

```bash
cd frontend
npm install
```

### 2.4 配置环境变量

```bash
cp backend/.env.example backend/.env
```

编辑 `backend/.env` 文件，配置以下内容：

```bash
# LLM API 配置（必须）
LLM_PROVIDER=deepseek
LLM_API_KEY=你的DeepSeek-API-Key
LLM_API_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-v4-pro

# Flask 配置
SECRET_KEY=随机生成的密钥
FLASK_DEBUG=True
PORT=5000

# 模型缓存路径（根据实际情况修改）
MODEL_CACHE_DIR=D:\funasr_chattts

# HuggingFace 镜像（国内网络必需）
HF_ENDPOINT=https://hf-mirror.com

# ASR 配置
ASR_MODEL=iic/speech_paraformer-large-vad-punc_asr_nat-zh-cn-16k-common-vocab8404-pytorch
ASR_DEVICE=cuda

# TTS 配置
TTS_MODEL=2Noise/ChatTTS
TTS_DEVICE=cuda
```

### 2.5 创建模型缓存目录

```bash
mkdir D:\funasr_chattts
```

## 3. 启动服务

### 3.1 启动后端

```bash
cd backend
python app.py
```

首次启动会自动下载模型：
- FunASR Paraformer-zh (~1GB)
- ChatTTS (~2-3GB)

### 3.2 启动前端

```bash
cd frontend
npm run dev
```

### 3.3 访问应用

打开浏览器访问 `http://localhost:3000`

## 5. 核心功能说明

### 5.1 Markdown 渲染
- 使用 `marked` 库渲染 Markdown
- 使用 `KaTeX` 渲染数学公式（`$...$` 和 `$$...$$`）
- 支持代码块、表格、列表、引用等

### 5.2 流式 TTS
- LLM 文本输出时实时检测句子边界
- 每个完整句子立即发送给 TTS 合成
- 前端维护音频队列，边接收边播放
- 大幅降低朗读延迟

### 5.3 朗读控制
- **朗读按钮**：点击立即切换开/关
  - 关闭时：立即停止当前播放
  - 开启时（回答进行中）：从当前位置继续播放
  - 开启时（新回复）：从头开始播放
- **音量调节**：滑动时实时调节当前播放音频的音量

### 5.4 TTS 文本清理
- 去除 Markdown 格式符号（#、*、`、[]等）
- 去除 Emoji 表情
- 保留数学符号（^、()、小数点等）
- LaTeX 公式转可读文本（`$E = mc^2$` → `E = mc^2`）

## 6. 常见问题

### Q1: 首次启动很慢？
A: 首次启动需要下载模型文件，总共约 3-4GB，请耐心等待。

### Q2: 提示 CUDA 不可用？
A: 请确保安装了正确版本的 PyTorch，并且 NVIDIA 驱动正常。

### Q3: 显存不足？
A: 可以尝试关闭其他占用显存的程序，或修改 `.env` 文件将 `ASR_DEVICE` 和 `TTS_DEVICE` 改为 `cpu`。

### Q4: 国内网络无法下载模型？
A: 确保 `.env` 文件中设置了 `HF_ENDPOINT=https://hf-mirror.com`。

### Q5: TTS 朗读不正常（漏字、乱读）？
A: 检查 `backend/api/websocket.py` 中的 `strip_markdown_for_tts()` 函数是否完整。

### Q6: 数学公式显示为 LaTeX 源码？
A: 确保前端已安装 `katex` 和 `marked-katex-extension`：`npm install katex marked-katex-extension`
